Question 001. A spreadsheet is best described as:

A. A presentation slide
B. A word processing document
C. A database query
D. An electronic worksheet of rows and columns used to organise and analyse data

Correct Answer: D

Explanation: Spreadsheets arrange data in a grid of cells.

Question 002. The most widely used spreadsheet application in accounting offices is:

A. Adobe Photoshop
B. Microsoft PowerPoint
C. Microsoft Excel
D. Microsoft Word

Correct Answer: C

Explanation: Excel dominates accounting and finance work.

Question 003. The intersection of a row and a column in a spreadsheet is called a:

A. Record
B. Slide
C. Cell
D. Field

Correct Answer: C

Explanation: Each cell has a unique address.

Question 004. A cell address such as B5 refers to:

A. Row B, column 5
B. Column B, row 5
C. Book B, cell 5
D. Sheet B, page 5

Correct Answer: B

Explanation: Columns are letters and rows are numbers.

Question 005. In Excel, columns are identified by:

A. Colours
B. Symbols
C. Letters
D. Numbers

Explanation: Columns run from A onwards.

Question 006. In Excel, rows are identified by:

A. Numbers

Explanation: Rows are numbered 1, 2, 3...
