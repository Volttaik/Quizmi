Question 001. The main reason economists use mathematics is to:

A. Replace economic reasoning entirely
B. Avoid using data
C. State relationships precisely and derive conclusions logically
D. Make economics purely normative

Correct Answer: C

Explanation: Mathematics is a tool for precision; economic content comes from assumptions.


Question 002. In the function Qd = 50 - 2P, P is the:

A. Constant
B. Independent variable
C. Dependent variable
D. Parameter only

Correct Answer: B

Explanation: Qd depends on P.


Question 003. In Qd = 50 - 2P, the number 50 is called:

A. The intercept (constant term)
B. The slope
C. The exponent
D. The dependent variable

Correct Answer: A

Explanation: It is Qd when P = 0.


Question 004. In Qd = 50 - 2P, the coefficient -2 represents:

A. The intercept
B. The price
C. The quantity at zero price
D. The slope, the change in Qd per unit change in P

Correct Answer: D

Explanation: Each N1 rise in P reduces Qd by 2.


Question 005. A parameter in an economic model is:

A. A variable that changes constantly
B. The dependent variable
C. Always zero
D. A constant that may change between situations but is fixed within one analysis

Correct Answer: D

Explanation: E.g. a and b in Q = a - bP.


Question 006. An endogenous variable is one:

A. That never changes
B. Whose value is determined within the model
C. Fixed from outside the model
D. That is always price

Correct Answer: B

Explanation: Exogenous variables are given from outside.


Question 007. An identity differs from an equation in that an identity:

A. Is always false
B. Has no variables
C. Holds for only one value
D. Holds true for all values of the variables

Correct Answer: D

Explanation: E.g. Y ≡ C + I + G in national accounts, by definition.


Question 008. Which is a behavioural equation?

A. TR ≡ P x Q
B. Y ≡ C + I
C. C = 100 + 0.8Y
D. Profit ≡ TR - TC

Correct Answer: C

Explanation: It describes how consumers behave; the others are definitions.


Question 009. An equilibrium condition in a market model is:

A. Qd = 100 - P
B. TR = PQ
C. Qd = Qs
D. Profit = TR - TC

Correct Answer: C

Explanation: It states the condition under which the market clears.


Question 010. If Y = C + I, C = 50 + 0.5Y and I = 30, equilibrium Y is:

A. 160
B. 130
C. 110
D. 80

Correct Answer: A

Explanation: Y = 50 + 0.5Y + 30, so 0.5Y = 80, Y = 160.


Question 011. A variable that can take any value within a range is:

A. Continuous
B. Qualitative
C. Discrete
D. Constant

Correct Answer: A

Explanation: E.g. price; discrete variables take separate values like number of cars.


Question 012. The number of workers in a firm is best described as:

A. An identity
B. A discrete variable
C. A parameter
D. A continuous variable

Correct Answer: B

Explanation: Workers are counted in whole numbers.


Question 013. A rational number is one that:

A. Is always negative
B. Can be expressed as a ratio of two integers with non-zero denominator
C. Is always a whole number
D. Cannot be written as a fraction

Correct Answer: B

Explanation: E.g. 3/4, -5, 0.25.


Question 014. Which of these is irrational?

A. 22/7
B. √2
C. 0.75
D. -3

Correct Answer: B

Explanation: √2 cannot be written as a fraction of integers; 22/7 is only an approximation of π.


Question 015. Real numbers consist of:

A. Only positive numbers
B. Only integers
C. Rational and irrational numbers
D. Only fractions

Explanation: All numbers on the number line.


Question 016. A set is best defined as:

A. A well-defined collection of distinct objects
B. Any group of numbers that repeat
C. An equation
D. A function

Correct Answer: A

Explanation: Membership must be clearly determinable.


Question 017. The symbol ∈ means:

A. "intersection"
B. "is an element of"
C. "union"
D. "is a subset of"

Correct Answer: B

Explanation: E.g. 3 ∈ {1, 2, 3}.


Question 018. If A = {2, 4, 6, 8}, then which is true?

A. 6 ∈ A
B. 2 ∉ A
C. 5 ∈ A
D. 8 ∉ A

Question 019. The set {x : x is a positive even number less than 10} in roster form is:

Question 020. The empty (null) set is:

A. A set containing zero

Question 021. Which set is empty?

A. {1}

Question 022. The universal set is:

A. The empty set

Question 023. A is a subset of B (A ⊆ B) if:

A. A and B have no common elements

Question 024. The number of subsets of a set with n elements is:

Question 025. The number of subsets of {a, b, c} is:

Question 028. The intersection A ∩ B consists of:

Question 035. De Morgan's law states that (A ∪ B)' equals:

A. A ∩ B
B. A ∪ B

Question 036. De Morgan's law states that (A ∩ B)' equals:

A. A ∪ B

Explanation: Solid means 2 is included.


Question 456. Which rule about inequalities is correct?

A. Adding a negative number reverses the sign
B. Multiplying both sides by a negative number reverses the sign
C. Dividing by a positive number reverses the sign
D. Squaring both sides always preserves the sign

Correct Answer: B

Explanation: Only multiplication/division by negatives flips it.


Question 457. If a > b, which is necessarily true?

A. 1/a > 1/b
B. -a > -b
C. a + 5 > b + 5
D. a² > b²

Correct Answer: C

Explanation: Adding the same number preserves order; others can fail.


Question 458. Solve x² < 9:

A. -3 < x < 3
B. x > 3
C. x < 3
D. x < -3 or x > 3

Correct Answer: A

Explanation: Squares less than 9 lie between -3 and 3.


Question 459. Solve x² - 5x + 6 > 0:

A. x < 2 or x > 3
B. x < 3
C. x > 2
D. 2 < x < 3

Correct Answer: A

Explanation: Roots 2 and 3; positive outside the roots for an upward parabola.


Question 460. Solve x² - 4x - 5 ≤ 0:

A. x ≤ 5
B. x ≤ -1 or x ≥ 5
C. -5 ≤ x ≤ 1
D. -1 ≤ x ≤ 5

Correct Answer: D

Explanation: (x - 5)(x + 1) ≤ 0 between roots.


Question 461. Solve (x - 1)(x + 4) < 0:

A. -4 < x < 1
B. x < -4
C. x > 1
D. x < -4 or x > 1

Correct Answer: A

Explanation: Product negative between the roots.


Question 462. Solve x² ≥ 16:

A. x ≥ 16
B. x ≤ -4 or x ≥ 4
C. x ≥ 4
D. -4 ≤ x ≤ 4

Correct Answer: B

Explanation: Outside the roots ±4.


Question 463. Solve the absolute-value inequality abs(x) < 5:

A. x < 5
B. x < -5 or x > 5
C. -5 < x < 5
D. x > -5

Correct Answer: C

Explanation: Distance from zero less than 5.


Question 464. Solve abs(x - 2) ≤ 3:

A. x ≤ 5
B. -5 ≤ x ≤ 1
C. x ≤ -1 or x ≥ 5
D. -1 ≤ x ≤ 5

Correct Answer: D

Explanation: -3 ≤ x - 2 ≤ 3.


Question 465. Solve abs(2x + 1) > 7:

A. x < -4 or x > 3
B. -4 < x < 3
C. x > 3
D. x < -4

Correct Answer: A

Explanation: 2x + 1 > 7 or 2x + 1 < -7.


Question 466. The region satisfying y ≥ 2x + 1 lies:

A. Below the line
B. On the y-axis only
C. On or above the line y = 2x + 1
D. To the left only

Correct Answer: C

Explanation: Test a point such as (0, 5).


Question 467. A budget constraint 10x + 20y ≤ 200 means the consumer:

A. Cannot buy anything
B. Can choose bundles on or below the budget line
C. Must buy only x
D. Must spend exactly 200

Correct Answer: B

Explanation: Spending cannot exceed income.


Question 468. Which point satisfies 2x + y ≤ 10, x ≥ 0, y ≥ 0?

A. (4, 3)
B. (6, 0)
C. (3, 4)
D. (5, 1)

Correct Answer: C

Explanation: 2(3) + 4 = 10 ≤ 10; others give 11, 11, 12.


Question 469. In linear programming, the feasible region is:

A. The area outside constraints
B. The objective function
C. The set of points satisfying all constraints
D. The optimal point only

Correct Answer: C

Explanation: Optimal solutions occur at its corners.


Question 470. In linear programming, the optimum of a linear objective function occurs:

A. Anywhere on the axes
B. At the centre of the region
C. At a corner (vertex) of the feasible region
D. Outside the region

Correct Answer: C

Explanation: Corner point theorem.


Question 471. Maximise P = 3x + 2y subject to x + y ≤ 4, x ≥ 0, y ≥ 0. The maximum is:

A. 12
B. 14
C. 10
D. 8

Correct Answer: A

Explanation: Corners (0,0)=0, (4,0)=12, (0,4)=8.


Question 472. Minimise C = 2x + 5y subject to x + y ≥ 6, x ≥ 0, y ≥ 0. The minimum is:

A. 6
B. 17
C. 12
D. 30

Correct Answer: C

Explanation: Corners (6,0)=12, (0,6)=30.


Question 473. A firm makes chairs (x) and tables (y). Labour: x + 2y ≤ 40 hours; non-negativity holds. Which combination is feasible?

A. (30, 10)
B. (10, 20)
C. (20, 10)
D. (40, 1)

Correct Answer: C

Explanation: 20 + 20 = 40 ≤ 40; others exceed 40.


Question 474. Non-negativity constraints in economic problems state that:

A. Prices must be zero
B. Profit must be positive
C. Quantities cannot be negative
D. Costs must be equal

Correct Answer: C

Explanation: E.g. x ≥ 0, y ≥ 0.


Question 475. A firm needs revenue R = 50Q to exceed cost C = 2000 + 30Q. The required output is:

A. Q > 40
B. Q > 2000
C. Q < 100
D. Q > 100

Correct Answer: D

Explanation: 50Q > 2000 + 30Q gives 20Q > 2000.


Question 476. A student needs an average of at least 60 over three tests. With scores 55 and 58, the third score x must satisfy:

A. x > 70
B. x ≥ 67
C. x ≥ 57
D. x ≥ 60

Correct Answer: B

Explanation: (55 + 58 + x)/3 ≥ 60 gives x ≥ 67.


Question 477. Demand Q = 100 - 2P must be at least 40. Price must satisfy:

A. P ≤ 30
B. P ≤ 20
C. P ≥ 70
D. P ≥ 30

Correct Answer: A

Explanation: 100 - 2P ≥ 40.


Question 478. Profit π = -Q² + 20Q - 64 is positive when:

A. Q < 4 or Q > 16
B. Q > 16
C. Q < 4
D. 4 < Q < 16

Correct Answer: D

Explanation: -(Q - 4)(Q - 16) > 0 between roots.


Question 479. If 0 < a < b, then which is true?

A. a² > b²
B. 1/a > 1/b
C. -a < -b
D. 1/a < 1/b

Correct Answer: B

Explanation: Taking reciprocals of positives reverses order.


Question 480. The inequality symbol ≠ means:

A. Not equal to
B. Greater than
C. Approximately equal
D. Less than or equal to

Correct Answer: A

Explanation: E.g. x ≠ 0.


Question 481. The interval notation [2, 5) represents:

A. 2 ≤ x ≤ 5
B. 2 < x < 5
C. 2 < x ≤ 5
D. 2 ≤ x < 5

Correct Answer: D

Explanation: Square bracket includes, round excludes.


Question 482. The interval (-∞, 3] represents:

A. x ≥ 3
B. x ≤ 3
C. x > 3
D. x < 3

Correct Answer: B

Explanation: Includes 3.


Question 483. The triangle inequality states that for real numbers a and b, abs(a + b) is:

A. Equal to abs(a) - abs(b)
B. Always equal to abs(a) + abs(b)
C. Greater than abs(a) + abs(b)
D. Less than or equal to abs(a) + abs(b)

Correct Answer: D

Explanation: Equality holds when a and b have the same sign.


Question 484. Solve 3(x - 2) ≥ 2(x + 1):

A. x ≥ 8
B. x ≤ 8
C. x ≥ 4
D. x ≥ -8

Correct Answer: A

Explanation: 3x - 6 ≥ 2x + 2.


Question 485. Solve (2x - 1)/3 > (x + 2)/4:

A. x > 5
B. x > 2
C. x > 10/11
D. x < 2

Correct Answer: B

Explanation: 8x - 4 > 3x + 6 gives 5x > 10.


Question 486. The number of terms in the AP 7, 10, 13, ..., 100 is:

A. 31
B. 33
C. 93
D. 32

Correct Answer: D

Explanation: (100 - 7)/3 + 1 = 32.


Question 487. The sum of all multiples of 5 from 5 to 100 is:

A. 2,100
B. 525
C. 1,000
D. 1,050

Correct Answer: D

Explanation: 20 terms: 20/2 x (5 + 100).


Question 488. The first term of an AP is 6 and the sum of the first 10 terms is 195. The common difference is:

A. 5
B. 2
C. 4
D. 3

Correct Answer: D

Explanation: 195 = 5[12 + 9d] gives 39 = 12 + 9d.


Question 489. A GP has first term 5 and 4th term 135. The common ratio is:

A. 9
B. 3
C. 4
D. 27

Correct Answer: B

Explanation: 5r³ = 135 gives r³ = 27.


Question 490. The sum of a GP is 1 + 3 + 9 + ... + 729. The number of terms is:

A. 7
B. 243
C. 6
D. 8

Correct Answer: A

Explanation: 3⁶ = 729, so terms are 3⁰ to 3⁶.


Question 491. Total sales double every year starting at 10 units. Total units sold over the first 6 years is:

A. 640
B. 320
C. 310
D. 630

Correct Answer: D

Explanation: 10(2⁶ - 1) = 630.


Question 492. (Revision) A firm's profits form a GP: N2m, N2.4m, N2.88m, ... The ratio and the 4th year's profit are:

A. 1.2 and N3.456m
B. 0.4 and N3.28m
C. 1.2 and N3.36m
D. 1.4 and N3.84m

Correct Answer: A

Explanation: r = 2.4/2 = 1.2; 2.88 x 1.2 = 3.456.


Question 493. (Revision) A consumer has N600 to spend on x (N20 each) and y (N30 each) and must buy at least 6 units of x. Which bundle satisfies 20x + 30y ≤ 600 and x ≥ 6?

A. (20, 8)
B. (5, 15)
C. (12, 13)
D. (15, 10)

Correct Answer: D

Explanation: 300 + 300 = 600 ≤ 600; (5,15) fails x ≥ 6; (20,8) costs 640; (12,13) costs 630.


Question 494. The 15th term of the AP -4, -1, 2, ... is:

A. 35
B. -46
C. 38
D. 41

Correct Answer: C

Explanation: -4 + 14(3).


Question 495. The sum of the first 8 terms of 2, 4, 8, ... is:

A. 512
B. 510
C. 256
D. 254

Correct Answer: B

Explanation: 2(2⁸ - 1) = 510.


Question 496. The sum to infinity of 1 - 1/2 + 1/4 - 1/8 + ... is:

A. Infinite
B. 1/2
C. 2
D. 2/3

Correct Answer: D

Explanation: 1/(1 - (-1/2)) = 2/3.


Question 497. Solve 4 - x < 2x + 1:

A. x > 5/3
B. x < 1
C. x > 1
D. x < -1

Correct Answer: C

Explanation: 3 < 3x.


Question 498. Solve 7 - 2x ≤ 3x - 8:

A. x ≥ 1
B. x ≤ 3
C. x ≥ -3
D. x ≥ 3

Correct Answer: D

Explanation: 15 ≤ 5x.


Question 499. Solve x² + x - 12 < 0:

A. -3 < x < 4
B. x < -4 or x > 3
C. x < 3
D. -4 < x < 3

Correct Answer: D

Explanation: (x + 4)(x - 3) < 0.


Question 500. N10,000 is deposited each year at the start of the year with no interest. If the target is at least N85,000, the minimum number of years is:

A. 85
B. 10
C. 9
D. 8

Correct Answer: C

Explanation: 10,000n ≥ 85,000 gives n ≥ 8.5, so 9 years.
